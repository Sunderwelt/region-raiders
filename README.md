# Region Raiders 🎰

An original mobile-first, Coin Master-style **virtual currency only** browser game. Phase 1 starts in Michigan City, Indiana.

## Play locally
Open `index.html` in a browser. No dependencies or build step needed.

## Features
- Three animated reels and randomized symbol rewards
- Virtual coins, spin tickets, and jackpot bonuses
- 1 free spin per minute (up to 50 in the bank)
- Five Michigan City landmarks with five upgrades each
- Upgrade prices scale by level
- Local browser progress saving
- Responsive Android, iOS, and desktop layout

## Publish using GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**, branch **main**, folder **/(root)**.
3. Visit `https://sunderwelt.github.io/region-raiders/` once deployment finishes.
